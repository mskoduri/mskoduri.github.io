# Invilynk — Mobile-First Digital Invitation Website

Ready-to-upload static website for GitHub Pages.

## Before publishing
Open `config.js` and replace:
- `demoUrl`
- `whatsappNumber`
- `phoneDisplay`
- `email`
- `instagramUrl`

The Madhu & Madhavi invitation is labelled as a demonstration invitation.

Prices are draft website content and should be confirmed before publishing.

No build process is required.
